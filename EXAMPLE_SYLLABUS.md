# Example Syllabus: 16-Week Bug Bounty Roadmap

Use this as a template when creating your first plan in LearnFlow AI.

---

## Bug Bounty Hunting - Complete 16-Week Program

### Phase 1: Foundations (Weeks 1-4)

**Week 1: Web Fundamentals**
- HTTP/HTTPS protocols deep dive
- Request and response anatomy
- Status codes (2xx, 3xx, 4xx, 5xx)
- Headers and their security implications
- Cookies, sessions, and tokens
- Same-Origin Policy basics

**Week 2: Networking & Infrastructure**
- TCP/IP fundamentals
- DNS and subdomain structure
- Port scanning basics
- Common web server configurations
- CDN and reverse proxy concepts
- SSL/TLS certificates

**Week 3: HTML, CSS & JavaScript Security**
- DOM manipulation
- JavaScript execution contexts
- Event handlers and their risks
- Browser security model
- Content Security Policy (CSP)
- CORS and security headers

**Week 4: Reconnaissance Fundamentals**
- Passive reconnaissance techniques
- Subdomain enumeration (Subfinder, Amass)
- Google dorking
- Shodan and Censys
- GitHub reconnaissance
- Wayback Machine analysis

### Phase 2: OWASP Top 10 (Weeks 5-8)

**Week 5: Injection Attacks**
- SQL Injection (SQLi) basics
- Blind SQLi techniques
- NoSQL injection
- Command injection
- LDAP injection
- PortSwigger SQL injection labs

**Week 6: Broken Authentication & Session Management**
- Authentication bypass techniques
- Session fixation
- Session hijacking
- Brute force attacks
- Password reset vulnerabilities
- OAuth misconfigurations

**Week 7: Cross-Site Scripting (XSS)**
- Reflected XSS
- Stored XSS
- DOM-based XSS
- XSS filter bypass techniques
- Mutation XSS
- PortSwigger XSS labs

**Week 8: Access Control & CSRF**
- Broken access control patterns
- IDOR vulnerabilities
- Path traversal
- CSRF attack vectors
- CSRF token bypass
- Privilege escalation

### Phase 3: Advanced Vulnerabilities (Weeks 9-12)

**Week 9: Server-Side Request Forgery (SSRF)**
- SSRF basics and impact
- Blind SSRF detection
- Cloud metadata exploitation
- SSRF filter bypass
- Real-world SSRF scenarios

**Week 10: XXE & Deserialization**
- XML External Entity (XXE) attacks
- Blind XXE techniques
- Insecure deserialization
- Java deserialization
- Python pickle vulnerabilities

**Week 11: Business Logic Flaws**
- Race conditions
- Payment manipulation
- Discount abuse
- Workflow bypass
- Rate limiting issues
- Logic flaw identification

**Week 12: API Security**
- REST API vulnerabilities
- GraphQL security issues
- API authentication flaws
- Mass assignment
- Excessive data exposure
- API rate limiting bypass

### Phase 4: Advanced Techniques (Weeks 13-16)

**Week 13: Advanced Recon & Automation**
- Nuclei templates
- Custom wordlist creation
- Automation with Python
- Burp Suite extensions
- CI/CD pipeline testing
- Asset monitoring

**Week 14: Mobile & Thick Client Testing**
- Android app security basics
- iOS security fundamentals
- API endpoint extraction
- Certificate pinning bypass
- Thick client vulnerabilities

**Week 15: Report Writing & Communication**
- Professional report structure
- Proof of Concept (PoC) creation
- Impact assessment
- Remediation recommendations
- Communication with security teams
- Building your reputation

**Week 16: Real-World Practice & Portfolio**
- HackerOne program selection
- Bugcrowd platform navigation
- Live target reconnaissance
- Responsible disclosure
- Building your portfolio
- Continuous learning strategies
